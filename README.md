A browser-based Pac-Man game developed using HTML, CSS, and JavaScript as part of a university assignment. The project demonstrates interactive gameplay mechanics, DOM manipulation, and basic animation techniques.

🔧 Technologies Used
- HTML5 for structure
- CSS3 for styling and layout
- JavaScript for game logic, movement, and collision detection
🎮 Features
- Classic Pac-Man grid layout
- Player-controlled movement using arrow keys
- Ghosts with randomized movement
- Score tracking and game-over conditions
